# Snippets HTML - Backlinks MAPSI -> Oling

Date: 3 juin 2026

Usage:
- coller ces blocs dans les pages `mapsi.fr` (zone "liens partenaires" ou "ressources");
- 1 a 2 liens max par page pour rester naturel.

## 1) Bloc expertise SI

```html
<section class="resource-links">
  <h3>Accompagnement AMOA complementaire</h3>
  <ul>
    <li><a href="https://oling.fr/amoa-si">AMOA SI et pilotage de programme</a></li>
    <li><a href="https://oling.fr/infrastructure-si-amoa">AMOA infrastructure SI</a></li>
  </ul>
</section>
```
